# Weekly Journal 7

## Exploration & Experimentation
This week was all about faces, and I took that as a personal attack (in a good way). I’ve been told I seem extroverted, which is funny because my closest friends know I am an introvert disguised as a functioning human. So naturally I thought of The Scream by Edvard Munch and went: yes, that’s the vibe sometimes. I started sketching a face concept that could hold duality—sun/moon, warm/cool, floral/mechanical.

I experimented with parameterizing features so I could generate variations instead of drawing one static face. I played with eye spacing, mouth curvature, and the balance between organic shapes (petal-like forms) and linear “cable” elements. I also started thinking about the sun and moon as faces—not just objects—because expression is a powerful shortcut for mood.

## Algorithmic Thinking
The machine imaginaire became a face generator: define a head shape, then place features according to adjustable parameters. If a “mood” variable is high, draw a smile arc; if low, draw a frown. If the style is warm, add petals or rays; if cool, add cables or crater textures. The core logic is conditional drawing: the same base face can output different identities depending on state.  
 
## Critical Reflection
What worked: I finally felt like my experiments were converging into a theme. What failed: when I tried to vary too many parameters at once, the face lost coherence and became chaos. I learned that generative freedom needs constraints. Next step: stop generating endless variations and start focusing on a strong two-state system with a smooth transition. I’m basically begging my future self to build a sketch that rotates between day and night like a calm, controlled cycle.
